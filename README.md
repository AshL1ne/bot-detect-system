# Bot Detect System

This repository contains a Spring Boot backend and a Vue frontend skeleton for a malicious user detection and visual analysis system.

## Structure
- bds: Spring Boot backend
- bds-web: Vue 3 frontend

## Quick start

Backend (Spring Boot):
- Configure database settings in bds/src/main/resources/application.properties
- Run the application

Frontend (Vue):
- Install dependencies and run the dev server

## Notes
- Auth uses username + password (hash + salt) with JWT planned.
- CORS and MyBatis-Plus pagination are configured.
